# Sika Coach — version TikTok & ventes (5 novembre au 31 décembre 2026)

Cette version recentre l’application sur l’acquisition de prospects et les ventes : 2 vidéos TikTok par jour, prospection ciblée, conversations qualifiées, suivis et enregistrement des paiements réellement encaissés.

## Contenu du Studio TikTok
Chaque journée contient deux kits de production : accroche, voix off à coller dans NaturalReader AI, scénario, prompt d’image, prompt vidéo Kling AI, consignes de montage CapCut, légende et appel à l’action. Les prompts sont des instructions à utiliser dans les applications ; l’application ne génère pas elle-même les images, la voix ou les vidéos.

## Mise à jour GitHub Pages
1. Décompressez cette archive.
2. Ouvrez le dépôt GitHub qui héberge Sika Coach.
3. Remplacez les fichiers du dossier `sika-skills-pwa` par ceux de cette archive, en conservant la structure.
4. Validez les changements (commit) et attendez la fin du déploiement GitHub Pages.
5. Sur le téléphone, fermez l’ancienne application installée puis ouvrez le site. Si l’ancienne interface reste en cache, actualisez le site ou videz le cache du navigateur avant de réinstaller.

## Données
Les cases cochées, notes et ventes restent stockées dans le navigateur de l’appareil. Le coach tente de reprendre l’ancien stockage `sika_objectif_1m_v1` pour conserver les progrès existants. Exportez une sauvegarde avant la mise à jour par précaution.

## Important
Les objectifs quotidiens d’activité (2 vidéos, 15 prospects, 5 conversations) sont des objectifs de travail, pas une promesse de conversion. Les prix ne sont pas préremplis : vérifiez les tarifs réels sur Chariow avant toute publication. Enregistrez uniquement les paiements reçus.
